# PREMO — Aplicativo de Monitoramento de Pressão Arterial

## Sobre o projeto

O PREMO é um projeto acadêmico desenvolvido durante a graduação em Sistemas de Informação, com a proposta de criar uma aplicação intuitiva para auxiliar no acompanhamento da pressão arterial.

O projeto foi idealizado com foco na acessibilidade e na facilidade de utilização, especialmente para pessoas idosas. A ideia é oferecer uma experiência simples, com informações organizadas e uma interface que facilite a navegação.

O PREMO busca explorar como a tecnologia pode contribuir para o acompanhamento de informações relacionadas à saúde por meio de uma aplicação pensada para as necessidades dos usuários.

## Problema identificado

A utilização de aplicações digitais pode ser um desafio para pessoas que não estão familiarizadas com interfaces tecnológicas complexas.

Diante disso, o projeto busca desenvolver uma solução que priorize a simplicidade, a clareza das informações e a facilidade de interação, considerando especialmente as necessidades do público idoso.

## Objetivos do projeto

- Desenvolver uma aplicação com interface intuitiva.
- Priorizar a acessibilidade e a facilidade de navegação.
- Facilitar o acompanhamento de informações relacionadas à pressão arterial.
- Aplicar conhecimentos de desenvolvimento de software adquiridos na graduação.
- Explorar soluções tecnológicas voltadas às necessidades dos usuários.

# Gerador de Currículo em Python

Projeto desenvolvido em Python para coletar informações pessoais e profissionais, armazená-las em arquivos de texto e gerar automaticamente um currículo em HTML com estilização em CSS.

## Funcionalidades

- Cadastro de informações pessoais, como nome, idade e e-mail.
- Cadastro de experiências profissionais.
- Registro de idiomas e seus respectivos dados.
- Armazenamento das informações em arquivos de texto.
- Leitura dos dados armazenados.
- Geração de um arquivo HTML com as informações do currículo.
- Aplicação de estilos CSS para melhorar a apresentação do documento.

## Tecnologias e conceitos

- **Python:** lógica de programação e organização das funções.
- **Manipulação de arquivos:** leitura e escrita de arquivos `.txt`.
- **HTML:** estruturação do currículo gerado.
- **CSS:** estilização da página.
- **Funções:** divisão do programa em etapas reutilizáveis.
- **Estruturas de repetição:** cadastro de múltiplos idiomas.

## Arquivos utilizados

| Arquivo | Finalidade |
|---|---|
| `main.py` | Código principal do programa. |
| `pessoas.txt` | Armazenamento dos dados pessoais. |
| `profissional.txt` | Armazenamento dos dados profissionais. |
| `idiomas.txt` | Armazenamento dos idiomas cadastrados. |
| `curriculo.html` | Currículo gerado pelo programa. |
| `foto.jpg` | Imagem utilizada no currículo. |

## Como executar

1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Coloque o arquivo `foto.jpg` na pasta esperada pelo programa.
4. Abra o terminal na pasta do projeto.
5. Execute:

   ```bash
   python main.py
   ```

   Se necessário, utilize `python3 main.py`.

6. Siga as instruções exibidas no terminal para preencher as informações.
7. Após a geração, abra o arquivo `curriculo.html` em um navegador.

## Objetivo

Aplicar conceitos de programação em Python, manipulação de arquivos e geração de conteúdo HTML, desenvolvendo uma aplicação capaz de transformar informações cadastradas em um currículo formatado.

## Status

Projeto acadêmico desenvolvido para praticar lógica de programação, funções, arquivos e integração entre Python e tecnologias web básicas.

# AUTOCAR — Sistema de Gestão Automotiva

Sistema de gerenciamento automotivo desenvolvido em linguagem C como projeto acadêmico. O programa permite cadastrar clientes e seus veículos, registrar serviços automotivos e consultar um relatório com os valores dos serviços.

## Funcionalidades

- Cadastro de clientes.
- Seleção do tipo de veículo: carro, moto, caminhonete ou caminhão.
- Registro de serviços automotivos.
- Consulta de valores dos serviços.
- Relatório de clientes, serviços e valores registrados.
- Menu interativo pelo terminal.

## Serviços disponíveis

| Serviço | Valor |
|---|---:|
| Troca de óleo | R$ 120,00 |
| Alinhamento | R$ 80,00 |
| Revisão geral | R$ 250,00 |
| Lavagem | R$ 40,00 |

## Tecnologias e conceitos

- Linguagem C.
- Estruturas condicionais (`if` e `switch`).
- Estruturas de repetição.
- Vetores e manipulação de dados.
- Entrada e saída de dados pelo terminal.
- Organização do programa em menus.

## Como executar

1. Tenha um compilador C instalado, como o GCC.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Compile o código:

   ```bash
   gcc main.c -o autocar
   ```

5. Execute o programa:

   ```bash
   ./autocar
   ```

   No Windows, execute:

   ```bash
   autocar.exe
   ```

## Objetivo

Praticar os fundamentos da programação em C por meio de um sistema de gerenciamento automotivo, aplicando lógica de programação, estruturas de controle e organização de dados.
